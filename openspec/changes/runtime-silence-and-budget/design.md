## Context

See proposal.md for motivation. The evidence base is the artifact-grounded classification of every capped runtime on the measured 0.15.0 production run and the 0.13.0 root-cause analysis of the same repository, both summarized deployer-neutrally in the runtime-contract, discovery, adjudication, and cloud-app-platform `context.md` files. Codex 0.152.0 source (tag `rust-v0.152.0`) was read for the streaming request, the reasoning-summary plumbing, and the environment policy. Sites re-resolved against 0.15.0 (`1b22eb6`): deadline race `runtimes/codex.py:374-377`, spawn and cleanup `runtimes/codex.py:160-197`, dead-lane rule `discover.py:34, 213-225`, adjudication all-invalid retry `adjudicate.py:400-412`, output instructions `prompts.py:29-40`, process runtime settings `summary.py:173-181` and the Worker parser `review-job-contract.ts:134-142`, App egress `sandbox-config.ts:14-27` and `review-job.ts:509-510`, image PATH `cloud/Dockerfile:17`.

## Goals / Non-Goals

Goals: stop paying a full deadline for a runtime that never produced a byte; tell lanes their time and tool budget and that coverage comes before exploration; make tool-call counts a recorded fact instead of a log-parsing exercise; keep review tool commands off remote git, the GitHub CLI, and arbitrary hosts without taking network away from the Codex CLI process or the CLI's own checkout and publication. Non-goals: `DEFAULT_DEADLINE_SECONDS`, `RVW_REVIEW_DEADLINE_SECONDS` (900), the 120-minute job cap, replica counts, the `exit_nonzero:124` redispatch rule, lane content, `when.paths`, chunking, model or reasoning effort, the publication view, i18n catalogs, Terraform, workflows, `CHANGELOG.md`.

## Decisions

1. The watchdog races inside the existing deadline. `execute_raw` awaits `asyncio.wait_for(_spawn_with_watchdog(...), timeout=deadline_seconds)`; the inner coroutine runs `_spawn` as a task and polls `run.log` size every 2 seconds. Growth is measured on the combined stdout+stderr log, so a runtime that prints `Reconnecting...` to stderr is alive. When the size has not changed for `no_output_seconds`, the spawn task is cancelled, which flows through `_cleanup_before_unwind` and `_terminate_and_reap` exactly as a deadline kill does, and the result is INVALID with reason `no_output_after:<N>s`. A deadline expiry still cancels the same task and still classifies as `exit_nonzero:124`; when `no_output_seconds >= deadline_seconds` the watchdog can never fire first.
2. The default is 660 seconds, not 180. The brief's 180 s default is safe only if reasoning summaries stream into the log during otherwise silent turns. Codex 0.152.0 cannot be shown to do that: the exec human-output processor renders a `Reasoning` item only when it completes (`exec/src/event_processor_with_human_output.rs:108-117`, dispatched from `ItemCompleted` at `:290`) and handles no summary-delta notification; the JSONL processor likewise emits reasoning on completion (`event_processor_with_jsonl_output.rs:151`). A tool-less replica's long think is a single reasoning item that completes immediately before the answer, so its summary cannot break the silence. Worse for the hypothesis, the production runs already requested summaries: `config.model_reasoning_summary` was unset (banner `reasoning summaries: none`), the model slug uses fallback metadata with `supports_reasoning_summary_parameter: true` and `default_reasoning_summary: Auto` (`models-manager/src/model_info.rs:143-166`), and `ResolvedStepSettings` uses that default (`core/src/session/step_settings.rs:59-61`), yet no reasoning text appears in any of the 25 retained logs. The legitimate tool-less silences were 426.6 s (0.13.0) and 546.6 s (0.15.0), so N must exceed 546.6 with margin; 660 is about 20% above the longest and still saves 240 s of the 900 s hang. At a 600 s deadline the watchdog is inert by construction.
3. `no_output_after:*` is transient. `dead_by_timeout` keeps matching only `exit_nonzero:124`: a deadline kill means the lane used every second it was given and a third identical run is deterministic waste, whereas a watchdog kill means the runtime never engaged and a fresh process usually does. A watchdog-killed lane therefore keeps its ordinary retry and its single coverage redispatch. Adjudication is unchanged: it retries only when all replicas are invalid, so an early kill of one replica leaves the other votes intact and the wave wall becomes `max(valid replica walls, N)` instead of the deadline.
4. Summaries are requested explicitly anyway. `CodexRuntimePolicy` gains `reasoning_summary = "detailed"` rendered as `-c model_reasoning_summary="detailed"`, so the banner records the request and, if the backend ever returns summaries, the agentic logs gain the model's stated intent before each tool call. The value is recorded in `usage.json`, `process.json runtime.reasoning_summary`, and `environment.txt`. Model and reasoning effort are untouched.
5. The budget contract lives in the shared output instructions and appears whenever the dispatcher knows the deadline. It states the wall budget in seconds, that coverage of every changed region comes first, that the final schema must be emitted immediately once every region is covered, that exploration beyond the changed regions is out of scope unless a finding's evidence requires it, a tool-call budget of 40 as guidance (valid lanes on the measured run used 3 to 8 tool commands, the one lane that converged used 33 and 7, dead lanes ran 41 to 95), and that remote repositories and APIs must not be fetched, cloned, or queried because base and head are available locally. Inline prompts, which run tool-less, receive the time and coverage sentences only. The text is English instruction-layer prose like the rest of the output instructions; the locale contract is unchanged.
6. Telemetry, not enforcement. At exit the runtime counts lines that are exactly `exec` and exactly `codex` in the log (the item headers Codex prints before a command and before an assistant message) and records them as `tool_calls` and `assistant_messages` on `RunUsage`; discovery copies them onto each persisted `RunAttempt`. Tool-less mode records zero tool calls as before. Nothing is killed on the budget.
7. Egress is layered, tightest viable first. (a) Codex `workspace-write` with network disabled was rejected: the image's `danger-full-access` selection rests on a measured bubblewrap failure inside a plain container, the runtime-contract spec pins it, and this change cannot prove nested namespaces on the production instance type from this host. (b) landed: `/opt/rvw-shims/{git,gh,curl,wget}` precede the real binaries in `PATH` and in `/etc/profile.d/rvw-shims.sh` (Codex runs tools through `bash -lc`); when `RVW_PHASE=review` the `git` shim refuses `fetch`, `pull`, `clone`, `ls-remote`, `push`, `remote add/set-url`, `submodule` and any `https://`, `ssh://`, `git://`, or `git@` argument with the one-line refusal `rvw: remote git is disabled during review` and exit 2, and the `gh`, `curl`, and `wget` shims refuse everything except `--version`/`help`; in any other phase every shim executes the real binary unchanged. The runtime spawns Codex with `RVW_PHASE=review` and `GIT_ALLOW_PROTOCOL=none` in the child environment (Codex inherits the full environment by default, `protocol/src/config_types.rs:207-218`; the second variable makes even `/usr/bin/git fetch` fail at git's transport check), and `checkout.py` runs its own commands with `RVW_PHASE=checkout`. The CLI process itself never carries `RVW_PHASE=review`, so target resolution and publication keep their `gh` access. (c) landed partially: `configureCodexEgress` now also calls `setAllowedHosts([proxyHost, "api.github.com", "github.com"])`; the pinned SDK already promotes the sandbox to intercept-all HTTP(S) because runtime `outboundByHost` overrides exist (`@cloudflare/containers` 0.3.7 `container.js` `shouldInterceptAllOutbound`), and an allowlist gates every proxied request (`ContainerProxy.fetch` step 2), so any other host answers 520. `github.com` cannot be removed for the whole run: the CLI clones inside the review process, so the Worker cannot order the removal after the clone without either a checkout marker polled at 30 s granularity or moving the clone ahead of `startProcess` behind `--repo-dir`; that gap is documented in `context.md` with the recommended follow-up. `api.github.com` stays because publication runs in the container.
8. New contract fields are additive. `RuntimeSettings` gains `no_output_seconds` (default 660) and `reasoning_summary` (default `detailed`), the process schema resource is regenerated, and the Worker parser accepts both as optional so legacy `process.json` still parses.

## Risks / Trade-offs

- A watchdog kill of a runtime that was about to answer costs one retry wave → N is above every legitimate silence measured so far and the kill is recorded with its own reason so the next measurement can retune it.
- Reasoning summaries, if the backend starts returning them, add output tokens and log bytes → they are bounded summaries and the log growth is exactly what the watchdog wants.
- A prompt budget makes lanes stop exploring → coverage of every changed region is required first, so the budget shortens tails without shrinking the reviewed surface.
- A PATH shim can be bypassed with an absolute path → `GIT_ALLOW_PROTOCOL=none` closes remote git at the transport layer and the Worker allowlist closes arbitrary hosts; `curl`/`wget` to the two GitHub hosts through an absolute path remains possible and is listed as a residual gap.
- The Worker allowlist blocks an HTTP host the pipeline turns out to need → the three listed hosts are the only ones the CLI and Codex use on the measured runs; a regression is visible on the first job as a neutral check whose `run.log` shows the 520, and the revert is one line.

## Migration Plan

Three staged conventional commits on one branch: runtime watchdog and summaries; prompt budget and telemetry; egress shims and Worker allowlist. Each stage updates the main specs and `context.md`. Legacy `process.json`, `usage.json`, and `discover.json` load with defaults. No deployment, push, or PR is part of this work; the change stays unarchived.
